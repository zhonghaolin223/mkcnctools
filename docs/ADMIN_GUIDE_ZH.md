# 铭凯五金刀具后台使用说明

后台入口：`/admin`。预览阶段使用 ChatGPT 的受保护登录：打开后台后会自动要求登录；本地预览会使用本地模拟登录。正式上线时，请由部署层（例如 Cloudflare Access）限制后台访问，仅授权给公司管理员。

## 日常操作

1. **网站设置**：先填写公司英文名称、正式域名、联系邮箱、电话、WhatsApp Business 国际格式号码、GA4/GTM ID。
2. **媒体库**：上传图片，写清楚英文 ALT 文本；产品图、工厂图和证书图都从这里复用。
3. **产品分类**：建立父分类或子分类，设置导航显示、排序、分类说明与 SEO。分类无需改代码。
4. **产品管理**：新增产品 → 填写英文名称、Slug、型号/SKU、分类、产品价格/报价方式、MOQ、一次选择多张图片、英文说明、动态参数 → 保存草稿 → 预览 → 确认后发布。价格可以填写 `USD 8.50 / pc`、`From USD 8.50 / pc`、`USD 8–12 / pc` 或 `Contact for Quote`；已发布产品自动出现在英文 Products 页面，草稿不会对公开访客显示。
5. **动态参数**：每条是“参数名称 + 参数值”，可自由增加，例如 `Tool Material | Carbide`，不受固定字段限制。
6. **询盘 CRM**：查看新询盘，记录跟进状态：新询盘、已联系、已确认、已关闭。该模块在产品上传验收后继续补齐。
7. **博客/页面**：先以草稿编辑英文内容和 SEO 字段，审核后再发布。

## 重要原则

- 不要把未确认的认证、产能、专利、客户数、出口国家或交期写进前台。
- 不要直接发布 Demo Product / Demo Category；它们只用于验证流程。当前预览数据库已清理，没有保留 Demo 数据。
- 发布前每个产品都应有英文标题、图片 ALT、描述、至少一个分类和有效询盘 CTA。
